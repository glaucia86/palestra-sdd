03 / GitHub Copilot Chat

GitHub Copilot Chat

Powered by AI
GPT-5.3-Codex Claude Sonnet 4.6 Claude Opus 4.6 Gemini 3.1 Pro 20+ models

GitHub Copilot Chat is Copilot's conversational interface. It lets you ask natural-language questions about code, generate implementations, debug, and in Agent Mode execute complex tasks autonomously.

  • Real-time completions while you type
  • Chat Panel for Q&A, explanations, and refactoring
  • Inline Chat ( Ctrl+I ) directly in the editor

03 / GitHub Copilot Chat — Modes

The 4 Copilot Chat Modes

Ask Mode

Conversational mode: ask questions, get explanations, discuss architecture. Copilot responds but does not edit files. Ideal for exploration.

Explore Mode

Read-only exploration — navigates the codebase with read tools (Grep, Glob, Read). Ideal to understand an unknown codebase without making changes. Currently available in VS Code Insiders.

Agent Mode ✦

Autonomous mode — runs end-to-end tasks: analyzes the codebase, decides which files to change, runs terminal commands, and iterates until done. The ideal mode for SDD.

Plan Mode

(Public preview) — Copilot creates a detailed implementation plan for human review before any code change. Perfect for SDD.

Explore → Plan → Agent: explore the codebase, create the plan, execute with structured context. The full SDD flow.

03 / GitHub Copilot Chat — Features

Main Features

Participants (@)

  • @workspace — whole-project context
  • @vscode — editor commands and settings
  • @terminal — terminal help
  • @github — PRs, issues, web search

Slash Commands (/)

  • /explain — explains selected code
  • /fix — fixes bugs automatically
  • /tests — generates unit tests
  • /doc — documents functions and APIs

Chat Variables (#)

  • #file — attaches file as context
  • #web — real-time web search
  • #selection — focuses on selected snippet
  • #codebase — indexes the entire workspace

MCP Integration

Model Context Protocol — open standard to connect Copilot to external tools: databases, APIs, cloud services. GitHub MCP Server already available.

Image Support

Attach screenshots (JPEG, PNG, GIF, WEBP) to describe UIs, explain architecture diagrams, or analyze visual issues with multimodal models.

Inline Chat

Ctrl+I directly in the editor — edit code without opening the side panel. Refactor any selection with natural language.

03 / GitHub Copilot CLI - Overview

GitHub Copilot CLI

Public Preview Terminal-first SDD-ready

Copilot CLI brings the GitHub Copilot experience to the terminal, complementing IDE chat with natural-language shell execution.

  • Official GitHub product for terminal engineering workflow
  • Complements Copilot Chat (does not fully replace the IDE)
  • Useful in SDD to explore, automate, and iterate tasks outside the editor
  • Supported plans: Pro, Pro+, Business, and Enterprise
IDE + Terminal = continuous context: specify in PRD, validate in plan, execute with traceability between editor and shell.

03 / GitHub Copilot — Agent Skills

Agent Skills — Dec/2025

GitHub Copilot natively supports Agent Skills — directories with a SKILL.md entrypoint, following the open agentskills.io pattern introduced by Anthropic for Claude Code and adopted by GitHub in Dec/2025.

  • Open standard: agentskills.io — directory spec with SKILL.md
  • Auto-discovery: Copilot scans .github/skills/ automatically
  • Progressive Disclosure: description always in context; full skill loaded on demand
  • Portability: same pattern works in Claude Code, Cursor, Gemini CLI, and other agents
  • VS Code: create Skills via chat — "@copilot create a skill for React patterns"

Skill Structure

.github/
└── skills/
    └── react-patterns/
        ├── SKILL.md        ← entrypoint
        ├── hooks.md
        └── examples/

SKILL.md — Entrypoint

---
name: react-patterns
description: React component patterns
  with hooks, Context API, and performance.
---

Load this skill when working
with React components. Includes:
hooks, Context, memo, lazy.
03 / GitHub Copilot Chat — SDD

GitHub Copilot + SDD = 🚀

The spec is the perfect prompt. When you provide GitHub Copilot with a well-structured PRD.md + AGENTS.md, it has the context needed to deliver what you need.
  • PRD.md as primary context via #file
  • AGENTS.md loaded automatically in Agent Mode
  • Agent Mode executes requirement by requirement with traceability
  • Plan Mode creates an implementation plan for human review
  • Iteration guided by PRD acceptance criteria (AC)

Prompt SDD Ideal

@workspace Based on:
- #file:PRD.md (requirements)
- #file:AGENTS.md (context)

Implement FR01 following
exactly acceptance criteria
AC01 and AC02. Write tests to
cover both described scenarios.
🎯 SDD turns vague prompts into precise instructions and GitHub Copilot into a predictable collaborator.
