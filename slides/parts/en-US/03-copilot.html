Agents

Four examples of surfaces and trade-offs; one SDD contract across all of them

Technical message: Copilot, Codex, Claude Code, and Devin represent different execution topologies; SDD provides the shared contract.

Executive message: tool choice does not replace clarity of outcome, boundaries, governance, and evidence.

Suggested KPI: percentage of slices accepted without significant rework, segmented by topology.

03 / AI Coding Agents

From Assistant to Agent

Assist

Suggest, explain, and review while a human directs every step.

Execute

Plan and modify multiple files within explicit boundaries.

Operate

Use tools, verify results, and stop at defined terminal states.

The greater the autonomy, the more important the contract: spec + context + permissions + verifiers.

Technical message: autonomy is a spectrum of capability and responsibility, not a binary mode.

Executive message: expanding autonomy without expanding controls increases the potential cost of error.

Suggested KPI: rate of unplanned human interventions per slice.

03 / Portable Contract

The Agent Changes. The Contract Remains.

Intent

Spec, outcome, out of scope, and acceptance criteria.

Context

AGENTS.md, Skills and sources of truth on demand.

Evidence

Checks, diff, review, handoff, and PR with a human gate.

Technical message: versioned artifacts reduce dependence on session memory and any specific interface.

Executive message: the durable investment is in a verifiable process, not a brand.

Suggested KPI: acceptance criteria with traceable evidence before the PR.

03 / Surfaces

A Surface Is a Topology Choice

Local and synchronous

IDE, CLI, and desktop keep the human, files, and feedback close.

Remote and asynchronous

Executive message: choose the topology by workflow, risk, and latency, not by feature count.

03 / Choose by Topology

Do Not Ask “Which Is Best?”

Where does it run?

Local, cloud, an isolated environment, or within the existing ecosystem.

How does it continue?

Synchronous, asynchronous, delegation, worktrees, or explicit handoff.

How does it prove?

Permissions, verifier, review, terminal state, and human gate.

Workload + risk + latency + integration + cost define the choice.

Technical message: a useful comparison starts with the workload and environment constraints.

Executive message: a tool portfolio can be healthy when there is a shared policy for use and acceptance.

Suggested KPI: accepted outcomes by workload type, without a vendor leaderboard.

Separate regimes

GitHub AI Credits; ChatGPT/Codex credits; OpenAI API; Devin quota, on-demand credits, or ACUs.

Unit of value

Compare cost per accepted outcome, with quality and within budget.

Technical message: each provider and authentication method has its own regime; do not convert units without an official rate.

Executive message: price per prompt or isolated token does not measure the cost of completed work.

Suggested KPI: total cost per accepted slice, including retries and review.
