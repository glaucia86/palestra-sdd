09 / Conclusion

One contract, from intent to outcome

Spec
Makes intent, acceptance criteria, and limits explicit before code.

Context
Reveals only the information needed for the current decision.

Slice
Delivers one verifiable outcome with controlled scope and WIP.

Handoff
Preserves state, evidence, risks, and the next action.

Harness
Turns policies into guides, sensors, checks, and observability.

Loop
Retries with budgets, terminal states, and a human gate — never unbounded autonomy.

The same contract can guide an agent in an IDE, terminal, or cloud VM.

Tools propose and verify; people remain accountable for intent, risk, acceptance, and publishing.

SpecContext · Slice · HandoffHarness · Loop · Human gate

Close the full arc: the spec defines intent; context selects knowledge; a slice bounds the outcome; handoff preserves continuity; the harness makes rules observable; the loop retries only within limits.
