GitHub Copilot Chat

Powered by AI
GPT-5.3-Codex Claude Sonnet 4.6 Claude Opus 4.6 Gemini 3.1 Pro +20 modelos

O GitHub Copilot Chat é a interface conversacional do Copilot. Permite fazer perguntas em linguagem natural sobre código, gerar implementações, depurar e, no Agent Mode, executar tarefas complexas de forma totalmente autônoma.

  • Completions em tempo real enquanto você digita
  • Chat Panel para Q&A, explicações e refatoração
  • Inline Chat ( Ctrl+I ) diretamente no editor
  • Agent Mode — execução autônoma e multi-etapas
  • Multi-modal — aceita screenshots como contexto

03 / GitHub Copilot Chat — Modos

Os 4 Modos do Copilot Chat

Ask Mode

Modo conversacional — faça perguntas, obtenha explicações, debata arquitetura. O Copilot responde mas não altera arquivos. Ideal para exploração.

Explore Mode

Exploração read-only — navega o codebase com ferramentas de leitura (Grep, Glob, Read). Ideal para entender uma base desconhecida sem fazer modificações. Disponível por enquanto na versão Visual Studio Code Insiders.

Agent Mode ✦

Modo autônomo — executa tarefas de ponta a ponta: analisa o codebase, decide quais arquivos mudar, roda comandos no terminal e itera até concluir. O modo ideal para SDD.

Plan Mode

(Public preview) — O Copilot cria um plano de implementação detalhado para revisão humana antes de qualquer mudança de código. Perfeito para SDD!

Explore → Plan → Agent: explore o codebase, crie o plano, execute com contexto estruturado. O fluxo completo do SDD.

03 / GitHub Copilot Chat — Features

Features Principais

Participantes (@)

  • @workspace — contexto do projeto inteiro
  • @vscode — comandos e settings do editor
  • @terminal — ajuda no terminal
  • @github — PRs, issues, busca web

Slash Commands (/)

  • /explain — explica o código selecionado
  • /fix — corrige bugs automaticamente
  • /tests — gera testes unitários
  • /doc — documenta funções e APIs

Chat Variables (#)

  • #file — anexa arquivo como contexto
  • #web — busca na web em tempo real
  • #selection — foca no trecho selecionado
  • #codebase — indexa o workspace inteiro

MCP Integration

Model Context Protocol — padrão aberto para conectar Copilot a ferramentas externas: bancos de dados, APIs, serviços cloud. GitHub MCP Server já disponível.

Suporte a Imagens

Anexe screenshots (JPEG, PNG, GIF, WEBP) — descreva UIs, explique diagramas de arquitetura ou analise erros visuais com modelos multimodais.

Inline Chat

Ctrl+I diretamente no editor — edite código sem abrir o painel lateral. Refatore qualquer seleção com texto natural.

03 / GitHub Copilot — Agent Skills

Agent Skills — Dez/2025

O GitHub Copilot suporta nativamente Agent Skills — diretórios com um arquivo SKILL.md como entrypoint, seguindo o padrão aberto agentskills.io introduzido pela Anthropic para o Claude Code e adotado pelo GitHub em Dez/2025.

  • Padrão aberto: agentskills.io — especificação de diretórios com SKILL.md
  • Auto-descoberta: Copilot varre .github/skills/ automaticamente
  • Progressive Disclosure: descrição sempre no contexto; skill completa carregada sob demanda
  • Portabilidade: mesmo padrão funciona no Claude Code, Cursor, Gemini CLI e outros agentes
  • VS Code: crie Skills pelo chat — "@copilot create a skill for React patterns"

Estrutura de uma Skill

.github/
└── skills/
    └── react-patterns/
        ├── SKILL.md        ← entrypoint
        ├── hooks.md
        └── examples/

SKILL.md — Entrypoint

---
name: react-patterns
description: Padrões de componentes React
  com hooks, Context API e performance.
---

Carregue esta skill ao trabalhar
com componentes React. Inclui:
hooks, Context, memo, lazy.
03 / GitHub Copilot Chat — SDD

GitHub Copilot + SDD = 🚀

A spec é o prompt perfeito. Quando você dá ao GitHub Copilot um PRD.md bem estruturado + AGENTS.md, ele tem todo o contexto necessário para entregar exatamente o que você precisa.
  • PRD.md como contexto principal via #file
  • AGENTS.md carregado automaticamente no Agent Mode
  • Agent Mode executa RF por RF com rastreabilidade
  • Plan Mode cria o plano de implementação para revisão humana
  • Iteração guiada pelos critérios de aceite (CA) do PRD

Prompt SDD Ideal

@workspace Com base em:
- #file:PRD.md (requisitos)
- #file:AGENTS.md (contexto)

Implemente o RF01 seguindo
exatamente os critérios de aceite
CA01 e CA02. Escreva testes para
cobrir os dois cenários descritos.
🎯 SDD transforma prompts vagos em instruções precisas e o GitHub Copilot em um colaborador previsível.
