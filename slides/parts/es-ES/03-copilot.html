03 / GitHub Copilot Chat

GitHub Copilot Chat

Powered by AI
GPT-5.3-Codex Claude Sonnet 4.6 Claude Opus 4.6 Gemini 3.1 Pro +20 modelos

GitHub Copilot Chat es la interfaz conversacional de Copilot. Permite hacer preguntas en lenguaje natural sobre codigo, generar implementaciones, depurar y, en Agent Mode, ejecutar tareas complejas de forma autonoma.

  • Completions en tiempo real mientras escribes
  • Chat Panel para Q&A, explicaciones y refactorizacion
  • Inline Chat ( Ctrl+I ) directamente en el editor
  • Agent Mode — ejecucion autonoma y multi-etapa
  • Multi-modal — acepta screenshots como contexto
GitHub Copilot hoy tiene cuatro superficies de interacción principales: sugerencias inline, panel de Chat, inline chat (Ctrl+I) y Agent Mode. Cada una sirve a un caso de uso diferente en el flujo SDD. Multi-modal es reciente e importante: poder adjuntar un screenshot de UI y pedir "implementa esto" reduce la brecha entre diseño y código.

03 / GitHub Copilot Chat — Modos

Los 4 Modos de Copilot Chat

Ask Mode

Modo conversacional: haz preguntas, obtien explicaciones y discute arquitectura. Copilot responde pero no modifica archivos. Ideal para exploracion.

Edit Mode

Ediciones directas en el editor — inline, multi-file, o via Ctrl+I. Ideal para iteraciones rapidas sin salir del contexto de codigo.

Agent Mode ✦

Modo autonomo — ejecuta tareas de punta a punta: analiza el codebase, decide que archivos cambiar, ejecuta comandos en terminal y itera hasta concluir. El modo ideal para SDD.

Plan Mode

Copilot crea un plan de implementacion detallado para revision humana antes de cualquier cambio de codigo. Perfecto para SDD.

Ask → Plan → Agent: entiende el codebase, crea el plan y ejecuta con contexto estructurado. El flujo completo de SDD.
Los cuatro modos tienen una progresión SDD natural: Ask para entender contexto, Edit para cambios rápidos y focalizados, Plan para revisar antes de editar, Agent para ejecución autónoma completa. En la práctica para SDD: empieza con Ask para entender el codebase → usa Plan para mapear qué se cambiará → desbloquea Agent Mode para ejecutar con un PRD.md estructurado como contexto.

03 / GitHub Copilot Chat — Features

Features Principales

Participantes (@)

  • @workspace — contexto del proyecto completo
  • @vscode — comandos y settings del editor
  • @terminal — ayuda en terminal
  • @github — PRs, issues, busqueda web

Slash Commands (/)

  • /explain — explica el codigo seleccionado
  • /fix — corrige bugs automaticamente
  • /tests — genera pruebas unitarias
  • /doc — documenta funciones y APIs

Chat Variables (#)

  • #file — adjunta archivo como contexto
  • #web — busca web en tiempo real
  • #selection — enfoca el fragmento seleccionado
  • #codebase — indexa el workspace completo

MCP Integration

Model Context Protocol — estandar abierto para conectar Copilot a herramientas externas: bases de datos, APIs y servicios cloud. GitHub MCP Server ya disponible.

Soporte de Imagenes

Adjunta screenshots (JPEG, PNG, GIF, WEBP) para describir UIs, explicar diagramas de arquitectura o analizar errores visuales con modelos multimodales.

Inline Chat

Ctrl+I directamente en el editor — edita codigo sin abrir el panel lateral. Refactoriza cualquier seleccion con lenguaje natural.

Las funcionalidades como @participantes, slash commands y variables de chat son las "palancas" de precisión del contexto. Cuanto más precisamente diriges a Copilot hacia el contexto relevante, mejor y más predecible es el resultado. En un flujo SDD: @workspace #file:PRD.md es el prompt base. Añadir #selection o #codebase según sea necesario. /tests después de implementar para cerrar el bucle de calidad.

03-B / GitHub Copilot CLI - Vista general

GitHub Copilot CLI

GA (25/02/2026) Terminal-first SDD-ready

Copilot CLI lleva la experiencia de GitHub Copilot al terminal, complementando el Chat del IDE con ejecucion guiada por lenguaje natural en shell.

  • Producto oficial de GitHub para flujo de ingenieria en terminal
  • Estado actual: GA desde 25/02/2026
  • Disponible para suscriptores de Copilot (Pro, Pro+, Business, Enterprise)
  • Business/Enterprise: admins habilitan y gobiernan via politicas
  • Complementa Copilot Chat (no reemplaza por completo el IDE)
  • Util en SDD para explorar, automatizar e iterar tareas fuera del editor
IDE + Terminal = contexto continuo: especifica en el PRD, valida en el plan y ejecuta con trazabilidad entre editor y shell.
El CLI para SDD: mismos principios, contexto de terminal. Puedes invocar comandos de spec-kit directamente desde el terminal con Copilot guiando la ejecución. Los usuarios de Business y Enterprise obtienen controles de política — esenciales para equipos que necesitan gobernanza sobre lo que el agente puede ejecutar.

03 / GitHub Copilot — Agent Skills

Agent Skills — Dic/2025

GitHub Copilot soporta nativamente Agent Skills — directorios con un archivo SKILL.md como entrypoint, siguiendo el patron abierto agentskills.io introducido por Anthropic para Claude Code y adoptado por GitHub en dic/2025.

  • Estandar abierto: agentskills.io — especificacion de directorios con SKILL.md
  • Auto-descubrimiento: Copilot escanea .github/skills/ automaticamente
  • Progressive Disclosure: descripcion siempre en contexto; skill completa cargada bajo demanda
  • Portabilidad: el mismo patron funciona en Claude Code, Cursor, Gemini CLI y otros agentes
  • VS Code: crea Skills por chat — "@copilot create a skill for React patterns"

Estructura de una Skill

.github/
└── skills/
    └── react-patterns/
        ├── SKILL.md        ← entrypoint
        ├── hooks.md
        └── examples/

SKILL.md — Entrypoint

---
name: react-patterns
description: Patrones de componentes React
  con hooks, Context API y performance.
---

Carga esta skill al trabajar
con componentes React. Incluye:
hooks, Context, memo, lazy.
Las Agent Skills son una capa de contexto poderosa introducida en diciembre de 2025. En lugar de sobrecargar al agente con todo el codebase, cargas solo la skill relevante para la tarea actual. El SKILL.md entrypoint se lee bajo demanda, no se carga en cada prompt. Este es el "Progressive Disclosure" del contexto en acción.
03 / GitHub Copilot Chat — SDD

GitHub Copilot + SDD = 🚀

La spec es el prompt perfecto. Cuando das a GitHub Copilot un PRD.md bien estructurado + AGENTS.md, tiene el contexto necesario para entregar exactamente lo que necesitas.
  • PRD.md como contexto principal via #file
  • AGENTS.md cargado automaticamente en Agent Mode
  • Agent Mode ejecuta requisito por requisito con trazabilidad
  • Plan Mode crea el plan de implementacion para revision humana
  • Iteracion guiada por criterios de aceptacion (CA) del PRD

Prompt SDD Ideal

@workspace Basado en:
- #file:PRD.md (requisitos)
- #file:AGENTS.md (contexto)

Implementa RF01 siguiendo
exactamente los criterios de
aceptacion CA01 y CA02. Escribe
pruebas para cubrir ambos escenarios.
🎯 SDD transforma prompts vagos en instrucciones precisas y vuelve a GitHub Copilot un colaborador predecible.
Esta es la diapositiva de integración práctica: PRD.md + AGENTS.md como el prompt estructurado. El contraste con los prompts desestructurados es notable: en lugar de "construye un sistema de autenticación", tienes un requisito específico con criterios verificables. Cierre: Copilot solo es tan predecible como el contexto que le das — SDD provee ese contexto de forma sistemática.
