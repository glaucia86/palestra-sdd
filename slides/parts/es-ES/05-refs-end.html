09 / Conclusión

Un contrato, desde la intención al outcome

Spec
Explicita intención, criterios de aceptación y límites antes del código.

Contexto
Revela solo la información necesaria para la decisión actual.

Slice
Entrega un outcome verificable, con alcance y WIP controlados.

Handoff
Preserva estado, evidencia, riesgos y la próxima acción.

Harness
Convierte políticas en guides, sensors, checks y observabilidad.

Loop
Reintenta con budget, terminal states y gate humano — nunca autonomía sin límites.

El mismo contrato puede guiar un agente en el IDE, terminal o una VM cloud.

Las herramientas proponen y verifican; las personas siguen responsables por intención, riesgo, aceptación y publicación.

SpecContext · Slice · HandoffHarness · Loop · Human gate

Cierra el arco completo: la spec define intención; el contexto selecciona conocimiento; el slice delimita el outcome; el handoff preserva continuidad; el harness hace observables las reglas; el loop reintenta solo dentro de límites.

El mismo contrato puede guiar un agente en el IDE, terminal o una VM cloud. La superficie no cambia la accountability.

El mensaje final es responsabilidad humana: narrativa, riesgo, aceptación, merge, release y deploy siguen siendo decisiones humanas.
