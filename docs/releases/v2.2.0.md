# v2.2.0 - Multilingual Runtime + In-App Language Toggle

## Resumo
Esta release transforma a apresentação em uma experiência multilíngue completa (PT-BR, EN-US e ES-ES), com troca de idioma diretamente na interface via toggle persistente.

## Destaques
- Runtime multilíngue por locale:
  - carregamento de manifesto por idioma (`manifest.pt-BR/en-US/es-ES`);
  - árvores de slides localizadas por idioma (`slides/parts/<locale>/*`).
- Conteúdo completo em EN/ES:
  - tradução integral dos blocos de slides;
  - remoção de conteúdo misto em português nos decks localizados.
- Quiz localizado por idioma:
  - dados de perguntas por locale;
  - labels e mensagens de validação localizadas.
- UX de idioma simplificada:
  - remoção do language gate inicial;
  - novo toggle fixo (`PT | EN | ES`) no shell da apresentação.
- Localização de textos dinâmicos em runtime:
  - dicas/easter egg no slide demo;
  - CTA/hints no encerramento (`the-end`) por idioma ativo.
