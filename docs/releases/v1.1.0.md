# v1.1.0 - Conteúdo, Confiabilidade, Performance e Acessibilidade

## Resumo
Esta release fortalece a palestra em três frentes:
- precisão técnica do conteúdo (nuances e disclaimers);
- robustez de execução (fallbacks e erros degradados);
- qualidade de UX (performance de DOM + reduced motion).

## Destaques
- Ajustes de conteúdo para feedback técnico:
  - SDD x TDD/BDD como analogia explícita e complementar.
  - Spec-kit com nuance de suporte a slash commands por integração.
  - AGENTS.md com texto mais preciso sobre suporte por ferramenta.
  - Rules atualizadas para `.github/copilot-instructions.md` e `.github/instructions/**` (quando suportado).
- Novos slides de credibilidade e operacionalização:
  - Limites e riscos do SDD.
  - Mini checklist de qualidade (Spec -> Plan -> Tasks).
  - Referências clicáveis de skills no slide de Skills.
- Quiz modernizado:
  - seletores centralizados;
  - cache de refs DOM;
  - event delegation com `data-quiz-action`;
  - validação explícita de contrato de dados com erro amigável.
- Performance e acessibilidade:
  - `DocumentFragment` para inserções em lote;
  - remoção de padrões custosos de `style.cssText` em loops;
  - suporte a `prefers-reduced-motion` no JS e no CSS.
- Bootstrap resiliente:
  - carregamento por parte com `Promise.allSettled`;
  - fallback por seção com lâmina de erro em modo degradado;
  - logs com contexto do path e motivo de falha.
